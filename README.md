# リアル倉庫番パズル

## 背景と目的

倉庫番は、箱を押して指定のマスに運ぶパズルのジャンルです。画面上ではボタンを押せば箱が隣のマスへ移りますが、物理的なロボットには箱への接近、接触、摩擦、回転を考えた押し動作が必要です。この作品では、倉庫番の盤面を探索で解き、各「1マス押す」動作をGazebo上のロボットで実行します。

正方形の箱ではルールベース制御でも局所的な押し動作に成功しやすかったため、三角形と星形の箱を対象に、学習した制御で押し動作が成立するかを検証しました。星形は5本の長方形の腕を重ねた剛体です。

## システムと役割分担

- **盤面の計画**：幅優先探索で、箱を押す順序と方向を決めます。ロボットが箱の後ろへ回り込む経路も、障害物と箱の輪郭を考慮した探索で求めます。ここは学習しません。
- **押し動作の実行**：ロボットの前後・左右の移動速度を、SACまたはルールベース制御が決めます。学習対象は、箱を隣の1マスへ押す間の速度の決め方だけです。
- **物理シミュレーション**：Docker内のROS 2 JazzyとGazebo Harmonicで、ロボット・箱・床・壁の接触と摩擦を計算します。ロボットは青い全方向移動の円柱としてモデル化しました。箱は接触で動き、実行中に箱の座標を直接書き換えません。

制御にはシミュレータが出す位置・速度・角度の数値を使用し、カメラ画像からの認識は行いません。箱は1個、盤面と箱の形は既知という設定です。1マスは0.8 mです。

## 学習と比較の設定

比較対象の **baseline** はルールベースのフィードバック制御です。箱とロボットの現在位置を見て、箱の後方への位置合わせ、横ずれの補正、目標に近づいた際の減速を行います。箱の角度を接触位置の計算に使いますが、目標角度へ積極的に回す制御はありません。baselineは学習しないため報酬も使いません。

学習には **SAC（Soft Actor-Critic）** を使います。SACは連続値の行動を学ぶ強化学習手法で、方策が観測から速度を出し、価値ネットワークが将来の報酬を見積もります。保存した過去の試行も再利用して更新します。三角形と星形で別々に、事前学習済みの重みを使わずゼロから学習します。

| 項目 | 設定 |
|---|---|
| 観測 | 箱・ロボットの相対位置や速度、箱の向き、周囲の壁など18個の数値 |
| 行動 | 押す方向を基準とする前後・左右の速度2成分。速度上限0.32 m/s |
| 1ステップ | 速度を1回指定し、物理シミュレーションを0.1秒進める操作 |
| 学習量 | 各形状15万ステップ。MLPは128ユニット×2層 |
| モデル選択 | 固定12条件（seed 10000〜10011）で成功数を比較。同数なら平均最終距離が短いモデルを選択 |
| 最終評価 | モデル選択に使っていない固定30条件（seed 20000〜20029）。baselineとSACに同じ初期条件を使用 |

主な報酬は箱が目標マスに近づくことです。三角形や星形は回転するとロボットとの接触位置が変わるため、基準の向きからの角度誤差が減る場合も小さく加点します。角度をそろえることは倉庫番のルールではなく、連続する押し動作を安定させるための実験上の設定です。成功時には追加の報酬を与えます。

局所的な1マス押しの成功条件は、箱の中心が目標から **0.056 m未満**、箱の移動速度が **0.06 m/s未満**、回転速度が **0.15 rad/s未満**、基準角度からのずれが **0.18 rad（約10.3度）未満**であることです。これを4ステップ連続で満たしたら成功と判定します。角度は形の回転対称性を考慮し、三角形では120度、星形では72度回した向きを同一視します。

## 盤面を通した実験

局所動作の評価とは別に、探索で計画した複数回の押しを実行して箱をゴールまで運べるかを確認しました。直進は2回、方向転換は4回の押しを計画します。迷路は2パターンです。

| 盤面 | 大きさ | 内部の壁 | 計画上の押し回数 |
|---|---:|---:|---:|
| 迷路（7×7） | 7×7マス | 2マス | 5回 |
| 迷路（9×9） | 9×9マス | 5マス | 8回、方向転換2回 |

9×9迷路は、壁を迂回して箱を運ぶ配置です（`#`：壁、`@`：ロボット、`$`：箱、`.`：ゴール）。

```text
#########
#       #
#    .  #
#       #
#  ###  #
#   ##  #
# @$    #
#       #
#########
```

## 確認済みの結果

以下はこのコードを使った実験で得た結果です。このフォルダには結果データや学習済みモデルを同梱していません。

| 箱の形 | baseline：局所30条件 | SAC：局所30条件 | baseline平均最終距離 | SAC平均最終距離 |
|---|---:|---:|---:|---:|
| 三角形 | 2/30成功 | 29/30成功 | 0.0650 m | 0.0279 m |
| 星形 | 12/30成功 | 29/30成功 | 0.0442 m | 0.0208 m |

三角形のSACは、学習2.5万ステップ時点の固定12条件で0/12成功、15万ステップ時点で12/12成功でした。星形は2.5万ステップ時点で12/12成功し、その後も11〜12件で推移しました。最終評価には、三角形で15万ステップ、星形で10万ステップのモデルを選びました。

盤面全体の確認では、直進・方向転換・7×7迷路を各形状1条件ずつ試し、SACは6事例すべてで計画した押しを完了しました。baselineはこの6事例でいずれも最初の押しが時間切れになりました。9×9迷路はSACだけを各形状1条件ずつ試し、三角形・星形とも8/8回の押しを完了しました。**9×9迷路のbaselineは実行していません。**

baselineは目標角度を追わず、SACは角度の改善を報酬に含めるため、両方式の成功数の差は参考値です。迷路も各形状・各盤面につき1条件の事例確認であり、未知の盤面や実機での成功率を示すものではありません。

## 再現手順

このフォルダにはソースコードと設定のみを収録しています。学習済みモデル、CSV、画像、動画、PDF、ビルド済みファイルは含めていません。Docker DesktopまたはDocker Engineを起動し、このREADMEがあるフォルダで実行してください。ホスト側のPythonやROSは不要です。初回のDockerイメージ構築と各形状15万ステップの学習には時間がかかります。

```sh
./run.sh build
```

形状ごとに次の順序で実行します。`smoke` は物理とカメラの動作確認、`baseline` と `evaluate` は局所30条件の評価、`puzzles` は直進・方向転換・7×7迷路での両方式の実行、`complex` は9×9迷路でのSAC実行です。`select` は学習中の固定12条件に基づいてモデルを選びます。

```sh
./run.sh shape triangle smoke
./run.sh shape triangle train 150000
./run.sh shape triangle select
./run.sh shape triangle baseline
./run.sh shape triangle evaluate
./run.sh shape triangle puzzles
./run.sh shape triangle complex

./run.sh shape star smoke
./run.sh shape star train 150000
./run.sh shape star select
./run.sh shape star baseline
./run.sh shape star evaluate
./run.sh shape star puzzles
./run.sh shape star complex
```

両形状の実行後に、学習曲線・形状図・動画を生成します。動画は迷路2パターン×両形状の計4事例を3倍速で表示します。

```sh
./run.sh learning-curve
./run.sh figures
./run.sh video
```

主な生成物は次の場所に保存されます。

| 内容 | 保存先 |
|---|---|
| 選択済みモデル | `experiments/<shape>/outputs/models/best.zip` |
| 局所30条件の結果 | `experiments/<shape>/outputs/baseline.csv`、`sac.csv` |
| 学習中の検証結果 | `experiments/<shape>/outputs/validation.csv` |
| 直進・方向転換・7×7迷路の結果 | `experiments/<shape>/outputs/puzzles.csv` |
| 9×9迷路の結果 | `experiments/<shape>/outputs/maze_complex_SAC_20000.json` |
| 学習曲線・形状図 | `experiments/shape_learning.png`、`report_assets/box_shapes.png` |
| 迷路2パターンの動画 | `experiments/maze_extended.mp4` |

`<shape>` は `triangle` または `star` に置き換えます。中断した学習の再開には `./run.sh shape triangle train 150000 --resume` を使えますが、保存済みのチェックポイントと経験バッファが必要です。再実行の結果は、実行環境や乱数によって上記の記録と完全には一致しない場合があります。
